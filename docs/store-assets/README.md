# App Store screenshots

Candidate screenshots for the Deltarium App Store listing, kept aside for the
submission. These are separate from the shots shown in the main README. They are
1290 by 2796, the 6.9-inch iPhone size the store asks for.

- `radioactivity.png`: the Carbon-14 decay curve, one half-life marked.
- `build-your-own-coefficients.png`: the coefficient sliders in Build Your Own.
- `build-your-own-equations.png`: the editable equations in Build Your Own.
